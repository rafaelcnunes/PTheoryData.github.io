# P(Theory | Data) Dark Universe Group

GitHub Pages site for the Cosmology Research Group at IF-UFRGS.

## Publishing

This is a Jekyll site. Create a repository named `darkcosmo.github.io` (or `YOURUSER.github.io`) and upload the contents of this directory. In **Settings → Pages**, select **Deploy from a branch**, branch `main`, folder `/ (root)`.

The lists of people, resources and Journal Club sessions are maintained in `_data/people.yml`, `_data/resources.yml` and `_data/journal_club.yml`.

Content was migrated and reorganized from the group's current Google Sites page.
